# 🚀 Narcy Dev — Portfolio Studio Software & Mobile

Bienvenue sur le dépôt officiel du portfolio de **Narcy Dev**, studio de développement de logiciels, d'applications web et mobiles modernes.

🌐 **Site en ligne :** [narcydev.site](https://narcydev.site)

---

## 📌 Présentation

Ce projet présente l'ensemble de mes réalisations, mes services, mes compétences techniques ainsi qu'un outil d'estimation de devis en ligne et un assistant IA interactif (**Narcy AI**).

### ✨ Fonctionnalités
* **Vitrine de projets :** Présentation dynamique des logiciels métiers, applications web et mobile (ex: *NARCY-SIG-COM*, *GbèPay*, etc.).
* **Outil d'estimation :** Calculateur interactif de devis pour les clients.
* **Assistant virtuel (Narcy AI) :** Chatbot de discussion intégré pour guider les visiteurs.
* **Responsive Design :** Interface fluide et optimisée sur ordinateur, tablette et smartphone.

---

## 🛠️ Tech Stack

* **Front-end :** React / TypeScript / Vite
* **Styling :** Tailwind CSS
* **Gestionnaire de paquets / Runtime :** Bun / npm
* **Déploiement & Hébergement :** Netlify (CI/CD via GitHub)
* **Domaine & DNS :** Spaceship / Netlify DNS
